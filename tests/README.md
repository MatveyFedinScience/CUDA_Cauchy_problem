# Тесты и временные файлы

Эта папка содержит временные файлы и тестовые версии кода, используемые во время разработки.

## Содержимое

- `main_backup.cu` - резервная копия оригинального main.cu до модификаций
- `test.cu`, `test2.cu` - тестовые файлы для проверки компиляции
- `.kilo/` - конфигурация и планы от инструмента Kilo

## Игнорирование

Файлы в этой директории игнорируются Git (см. `.gitignore`):
- Все `.cu`, `.o`, `.ppm`, `.png` файлы в tests/
- Исключение: `README.md`

## Очистка

Для очистки тестовых файлов:
```bash
rm tests/*.cu tests/*.o tests/*.ppm tests/*.png 2>/dev/null || true
```
